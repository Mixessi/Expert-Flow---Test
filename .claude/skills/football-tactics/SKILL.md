# 足球技战术分析 (Football Tactics Analysis)

把零散的比赛信息（文字、数据、画面、战术板）转化为**有条理、看得懂、讲得明白**的技战术分析。
风格定位：**解说 + 科普**——像顶级解说嘉宾一样把专业战术讲到球迷能听懂，既有干货又不堆术语。

## 何时使用本 skill

满足以下任一情况即触发：
- 用户要求分析某场/某队/某球员的战术、阵型、攻防体系、表现
- 用户给出比赛数据、热区图、传球网络、xG 等让你解读
- 用户上传了比赛截图、视频画面、阵型图、战术板请你解读站位与跑位
- 用户问"为什么这么踢""怎么破解对方战术""这套体系强在哪"等战术问题

## 核心工作流程

### 第 1 步：识别输入类型并提取信息
根据输入类型采取不同提取策略（详见 `references/analysis-framework.md`）：

| 输入类型 | 提取重点 |
|---------|---------|
| 文字/比赛描述 | 阵型、关键事件、攻防倾向、用户关注点 |
| 数据/统计表格 | 控球率、传球成功率、xG、跑动、压迫指标(PPDA)、热区 |
| 截图/视频画面 | 球员站位、阵型形状、攻防转换瞬间、空间分布 |
| 阵型图/战术板 | 阵型结构、职责分工、设计意图 |

**信息不足时**：先说明当前能确定什么、缺什么，再基于合理假设分析，并标注"以下为基于 XX 的推断"。不要编造具体比分、球员名或数据。

### 第 2 步：套用四阶段分析框架
足球的本质是四个阶段的循环，任何分析都从这四点切入（详见 `references/analysis-framework.md`）：
1. **进攻组织**（持球）——如何把球推进到威胁区域
2. **攻防转换**（丢球瞬间）——丢球后的反抢/退防
3. **防守组织**（无球）——如何限制对手、保护球门
4. **守防转换**（抢断瞬间）——夺回球权后的反击/控球

### 第 3 步：结合阵型与战术概念
- 阵型查 `references/formations.md`（4-3-3 / 4-2-3-1 / 3-5-2 等的结构与优劣）
- 术语查 `references/tactical-concepts.md`（高位压迫、区域防守、肋部、第三人跑动等）
- **每个专业术语第一次出现时用一句话科普**，例如："PPDA（每次防守动作允许对手的传球数，数值越低代表压迫越凶）"

### 第 4 步：按模板产出报告
使用 `templates/report-template.md` 的结构，但根据问题规模灵活裁剪：
- 简单提问 → 直接给 2-3 段精炼解读，不必套完整模板
- 完整赛事/球队分析 → 套用完整模板

## 风格要求（解说 + 科普）

1. **先讲人话，再上术语**：先用生活化比喻说清楚现象，再补专业名词。
   - ✅ "他们像织网一样在中场层层逼抢，专业上叫'高位压迫'。"
2. **有画面感**：多用"球往哪走、人往哪跑、空间在哪"的空间叙述。
3. **讲清因果**：不只说"发生了什么"，更要说"为什么""带来什么后果"。
4. **结论先行**：每个小节先给一句话核心判断，再展开论证。
5. **客观克制**：区分"事实"与"推断"；没有数据支撑时不要给出精确数字。
6. **适度类比**：可类比知名球队/教练风格帮助理解，但注明是类比。

## 重要原则

- **不臆造事实**：比分、球员名、具体数据若未提供，不得虚构。可分析"模式"与"倾向"。
- **承认不确定性**：画面/数据有限时，明确说明分析边界。
- **双向视角**：好的战术分析既看一方做得好，也看对手为何被针对、如何破解。
- **可落地**：科普之外，尽量给出"怎么打/怎么破"的具体建议。
