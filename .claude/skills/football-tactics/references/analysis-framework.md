# 分析框架与输入处理

## 一、四阶段分析框架（Game Model）

现代足球把一场比赛拆成不断循环的四个阶段。任何战术分析都可以从这四个角度切入，确保不遗漏。

### 1. 进攻组织（In Possession / 持球）
球队持球时如何由后向前推进、制造射门机会。
- **出球（Build-up）**：门将+后卫如何摆脱第一道压迫？是短传渗透还是长传找点？中卫是否分边、后腰是否回撤接应（落位/dropping）？
- **推进（Progression）**：通过中场还是边路？靠个人带球还是配合（撞墙、三角传递、第三人跑动）？
- **终结（Finishing）**：进攻最后 30 米如何制造和把握机会？传中、肋部渗透、远射、定位球？
- 关注：进攻宽度（拉边）、纵深（前插）、人数支援、节奏变化。

### 2. 攻防转换（Transition to Defense / 丢球瞬间）
丢球后最初 5-6 秒的选择，往往决定攻守。
- **就地反抢（Counter-press / Gegenpressing）**：丢球后立刻围抢，趁对手未站稳夺回球权。
- **快速退防（Fall back）**：放弃反抢，迅速收缩回防守阵型。
- 关注：丢球时的人员结构是否失衡？反抢的触发条件和包夹人数？

### 3. 防守组织（Out of Possession / 无球）
对手持球时如何限制其进攻、保护球门。
- **防守高度**：高位压迫 / 中场逼抢 / 低位防守（落位铁桶）。
- **防守方式**：盯人 / 区域 / 混合；压迫的诱导方向（逼向边路还是中路）。
- **防线组织**：防线高度、保持紧凑（横向间距）、层次（纵向间距）、越位陷阱。
- 关注：阵型在防守时的形状（如 4-3-3 防守变 4-1-4-1 还是 4-4-2）。

### 4. 守防转换（Transition to Attack / 抢断瞬间）
夺回球权后的第一选择。
- **快速反击（Counter-attack）**：趁对手阵型未回收快速直插。
- **控球缓冲（Settle / 控制节奏）**：先稳住球权重新组织。
- 关注：抢断后第一脚出球质量、前场支点与跑动接应。

## 二、不同输入类型的处理方法

### A. 文字 / 比赛描述
1. 提炼用户给出的：阵型、比分趋势、关键事件、明显的攻防倾向。
2. 标出用户的真正关注点（"为什么输""怎么破解""谁踢得好"）。
3. 缺失信息用合理假设补足，并明确标注为推断。

### B. 数据 / 统计表格（CSV / JSON）
1. 先读懂字段含义，必要时用代码做汇总/对比（控球、传球、xG、跑动等）。
2. **看相对值与对比，而非孤立数字**：与对手对比、与赛季均值对比。
3. 用数据**验证或推翻**肉眼判断，找出"数据与观感矛盾"的有趣点。
4. 常见指标解读见下方第三节。

### C. 截图 / 视频画面（图像）
1. 描述可见的**球员分布与阵型形状**（几条线、各线人数、横纵间距）。
2. 判断这是哪个阶段（进攻组织/转换/防守）。
3. 找**空间**：哪里人多（拥挤）、哪里有空当（可利用的空间）。
4. 看**身体朝向与重心**判断下一步意图（接球面向、防守是否落位）。
5. 单帧只是瞬间，明确说明"基于此画面"，不要过度外推整场。

### D. 阵型图 / 战术板
1. 解析阵型结构与每个位置的职责。
2. 推断设计意图（想控球？想反击？想压缩哪块空间？）。
3. 指出潜在弱点与对手可能的针对点。

## 三、常用数据指标速查（带科普解释）

| 指标 | 含义 | 怎么看 |
|------|------|--------|
| 控球率 (Possession %) | 控球时间占比 | 高不等于强；要看"控球质量"——是否进入危险区域 |
| xG (预期进球) | 根据射门质量算出的"该进几个" | xG 远高于实际进球=把握机会差；远低于=运气好/门将神勇 |
| xGA (预期失球) | 对手射门质量折算的"该丢几个" | 衡量防守是否真的稳，还是靠门将救险 |
| PPDA | 每次防守动作允许对手传球数 | **越低=压迫越凶**（让对手没传几脚就被逼抢） |
| 传球成功率 | 完成传球占比 | 要结合传球方向；横/回传成功率高没意义，看向前传球 |
| 进攻三区传球 | 进入对方禁区前 1/3 的传球 | 衡量进攻是否真有威胁 |
| 高强度跑动 | 冲刺/高速跑距离 | 反映压迫与转换的体能投入 |
| 抢断/拦截位置 | 夺回球权的平均位置 | 越靠前=防线越高、压迫越主动 |
| 传球网络 (Pass Network) | 球员间传球连线 | 看哪两人联系最密、谁是枢纽、阵型实际重心偏向 |
| 热区图 (Heat Map) | 活动密集区域 | 判断球员/球队实际占据的空间，对比理论站位 |

> 提醒：所有指标都要**结合比赛情境**。例如领先方控球率低很正常（主动让出球权打反击）。

## 四、分析自检清单

完成分析前快速核对：
- [ ] 是否覆盖了四个阶段（至少进攻+防守两端）？
- [ ] 是否区分了"事实"与"推断"？
- [ ] 专业术语是否都做了科普？
- [ ] 是否给出了"为什么"而不只是"是什么"？
- [ ] 是否兼顾了双方视角（含破解思路）？
- [ ] 没有数据支撑的地方是否避免了编造具体数字？
