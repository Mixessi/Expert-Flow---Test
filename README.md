## 今日头条战略复盘（2012–2026）可视化专题页

`index.html` 是一个单文件、自包含的可视化网页，以战略分析师视角梳理今日头条 14 年发展史。

**打开方式**：直接用浏览器打开 `index.html` 即可（无需构建或安装依赖）。图表库 ECharts 通过 CDN 加载；若处于离线环境，图表区会自动降级为数据表格与 CSS 条形图，页面其余内容不受影响。

**内容板块**：
1. 核心指标总览（Hero 数字卡）
2. 五个战略阶段带（执行摘要）
3. 互动时间线（41 条事件，可按 产品/资本/监管与诉讼/生态 筛选）
4. 数据透视三图：用户增长、融资估值阶梯（对数轴）、商业化双联图
5. 产品生态演化矩阵（头条系 → 字节系）
6. 移动资讯竞争格局甘特条带
7. 三场关键战役专题（版权争议 / 监管整改 / 头腾大战）
8. 战略启示与分析师结语

**数据口径**：数字综合自公开报道与第三方机构估算（澎湃、36氪、虎嗅、QuestMobile 等），凡标注"约 / 估 / E"者均为非官方口径，详见页脚免责声明。全部史实数据集中在页面源码的 `const DATA` 对象中，便于修订维护。
